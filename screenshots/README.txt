Screenshot placeholders
========================
This project was generated in a headless environment without a display,
so Tkinter screenshots could not be captured automatically.

To generate real screenshots:
  1. pip install -r requirements.txt
  2. python main.py
  3. Take screenshots of the Password / Passphrase / History / Statistics
     tabs in both light and dark theme.
  4. Save them here as: main_dark.png, main_light.png, history_tab.png,
     stats_tab.png, qr_code.png
  5. Reference them in README.md (the image links are already scaffolded
     there and just need these files to exist).
